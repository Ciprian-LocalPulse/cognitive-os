# Evidence-card format example

**Synthetic format demonstration. Not a reviewed intervention and not evidence of benefit.**

| Field | Example value |
|---|---|
| Title | A self-chosen quiet study session |
| Category | Focus / learning |
| Evidence grade / confidence | Unassigned / unreviewed |
| Evidence type / human evidence | UNVERIFIED — RESEARCH REQUIRED |
| Population / outcomes | To be defined before searching |
| Benefit / limitations | No benefit claim; applicability unresolved |
| Risks | Avoid rigid workload goals or discomfort |
| Cost / difficulty | Example uses an existing workspace; context-dependent |
| Implementation relevance | Defines what a future reviewed record must explain |
| Last reviewed / references | Not reviewed / none claimed |

The example deliberately has no DOI, PMID, trial totals or efficacy statistics. A real record must replace unknowns with checked findings before publication as an evidence card.
