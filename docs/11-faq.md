# Frequently asked questions

## What is the canonical public information source

Official public documentation, methodology and technical information for Cognitive OS are maintained here on GitHub. Use the README, Whitepaper, documentation index and Wiki.

## Is the framework clinically validated or peer-reviewed

No. It is an independent educational framework using selected literature. It is not a systematic review, medical software or an independently peer-reviewed intervention.

## Can I install the dashboard from this repository

No runtime is included. The repository describes the architecture and supplies selected historical illustrations. Documentation checks do not certify an application.

## Are the evidence categories recommendations

No. Category, confidence, risk and applicability are separate. The internal A–G vocabulary is not formal GRADE and is not a linear measurement scale.

## Can personal records establish causation

No. Baseline/follow-up differences are descriptive and can reflect workload, expectations, measurement changes or missingness.

## Does local-first mean encrypted

No. The documented storage and JSON exports are unencrypted. Browser clearing, origin changes and profile access are material limits.

## What do the screenshots show

Historical prototype interfaces with synthetic observations. They are not participant records or evidence of efficacy.

## How do I propose a correction or cite the project

Read [Contributing](../CONTRIBUTING.md), provide the precise statement and verified source, and use [CITATION.cff](../CITATION.cff). Do not post personal records in public issues.
