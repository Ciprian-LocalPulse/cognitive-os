# Glossary

| Term | Meaning in this framework |
|---|---|
| Evidence category | Contextual A–G description of support, consistency or directness |
| Confidence | Security of the bounded appraisal, separate from category |
| Verification | Checking source identity and recording access scope |
| Appraisal | Assessing design, relevance, outcomes and limitations |
| Directness | How closely evidence addresses the actual question |
| Association | Recorded variables varying together, without establishing cause |
| Causal inference | A conclusion about cause requiring a suitable design and assumptions |
| Self-observation | Voluntary description of selected ordinary activity |
| Baseline | A bounded reference period with explicit coverage |
| Follow-up | A later observation period, whose context may differ |
| Missingness | Absence of an observation, distinct from a recorded zero |
| Local-first | Ordinary records remain on the user's device by design |
| Origin | Browser context that determines access to local storage |
| JSON backup | Structured export intended for restoration |
| CSV export | Tabular observations for inspection, with units and missingness |
| Deterministic artifact | Identical output from identical inputs and fixed settings |
| Peer review | Independent assessment with documented scope; not claimed here |
| N-of-1 learning | Informal personal educational reflection, not a clinical trial designation |
| Transfer | Use of learning in a different task or setting |
| Retention | Availability of learned material over time |

These working definitions support consistent reading. They do not create diagnostic constructs or a formally validated terminology system.
