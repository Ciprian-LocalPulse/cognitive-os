# Repository operations
Default branch: main. Stable public documentation belongs here; commercial branches never do. Develop is optional and is not required for this small preview.

Recommended branch protection: disallow force pushes and deletion; require the three public check jobs; resolve review conversations before merging. With additional collaborators, require a human review and avoid administrator bypass. Enforce after the initial workflows are confirmed.

GitHub private vulnerability reporting, secret scanning and push protection should be enabled where the account/repository supports them. The lightweight security workflow checks public boundaries and common patterns; it is not a replacement for platform scanning or human review.

The social-preview PNG is supplied with a JPEG upload derivative below GitHub's 1 MB limit. The derivative preserves the artwork and dimensions; it changes encoding only. A public release includes only the public Git archive and explicitly selected public assets. The private paid product is never attached to releases.
