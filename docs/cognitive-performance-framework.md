# Cognitive-performance framework
| Step | Question | Educational output |
|---|---|---|
| Baseline | What do I actually observe? | Consistent units, context and missingness |
| Goal | What behavior is feasible? | One concrete learning/work habit |
| Selection | What evidence applies to this context? | Grade, confidence and limitations |
| Implementation | What is the smallest workable action? | Cue and routine |
| Observation | What changed alongside it? | Descriptive records and confounders |
| Review | Keep, simplify or stop? | Documented adjustment |

Focus, attention, memory and learning interact with daily context, workload, recovery and environment. This framework does not reduce them to one brain score or diagnose a condition. The commercial guide's explanatory content and specific routines remain private and under development.
